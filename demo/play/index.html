  1. Connect Twitch, confirm clear space, and start a keyboard or webcam fight.
  2. In OBS add Window Capture and choose this Chrome window.
  3. Enable Green background here; add a Chroma Key filter in OBS and choose green.
  4. Windows: in Window Capture tick “Capture Audio”, or add an “Application Audio Capture” source for Chrome.
  5. macOS: use “macOS Screen Capture” set to Window and tick “Capture Audio”.
  6. Test: press M, you should see the Chrome audio meter move in OBS.
  7. Crop to the game frame, check both rails are visible, then go live.
