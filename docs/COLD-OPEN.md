Use the no-login demo's Rehearse 5-second cold open button with clear space confirmed. Choose keyboard or start/calibrate the webcam first. Chat is always labelled SIMULATED; the guard comes only from the player. This is rehearsal tooling, not recorded proof.

| Time from button | Picture / action |
|---|---|
|0.0–0.8s|HANDS UP! + JAB/shield. Hold actual K/face-height guard.|
|0.8–1.5s|The actual reducer resolves BLOCK/PERFECT, damages the boss and shows BLOCKED! with sound if enabled.|
|1.5–5.0s|Tally highlighted: three simulated JAB votes. Keep the SIMULATED label visible.|

The rehearsal deliberately pauses after its first resolved attack to hold the shot. Normal game FX do not pause the engine. If guard is absent, the attack hits; no BLOCKED! is fabricated and the take fails. Use New match to return to ordinary play.
